# CLAUDE.md

QueueBuddy (Bengaluru) is a mobile-first app for booking verified human line-waiters ("Queue Buddies") at government offices (RTO, Sub-Registrar, Passport Seva Kendra, BBMP, BESCOM/BWSSB, Taluk). It is a Next.js web app, also installable as a PWA, and wrapped as an Android app with Capacitor.

## Stack

- **Web:** Next.js 14 (App Router) + TypeScript + Tailwind CSS, Framer Motion, TanStack Query, react-hook-form + zod, MapLibre GL (OSM tiles).
- **Backend:** Supabase (Postgres + RLS, Auth, Edge Functions, `pg_cron`).
- **Payments:** Razorpay in test mode; webhook verified with HMAC-SHA256.
- **Mobile:** Capacitor 8 (Android only), app id `com.queuebuddy.app`, plugins: camera, geolocation, push-notifications.
- **Hosting:** Vercel.

## Commands

```bash
npm run dev          # Next dev server on http://localhost:3000
npm run build        # Production build
npm run lint         # next lint
npm run cap:sync     # Copy web config/plugins into android/
npm run cap:run      # Build + install + launch on a device/emulator
npm run cap:build    # ./gradlew assembleDebug
```

There is no test suite.

## Layout

- `src/app/` – routes: `/` (public office directory), `/login`, `/app` (customer), `/buddy`, `/buddy/login`, `/buddy/apply`, `/admin`, `/admin/login`, `/account`, `/demo`, and `api/webhooks/razorpay`.
- `src/components/` – UI grouped by feature (`booking/`, `buddy/`, `admin/`, `offices/`, `map/`, `layout/`, `pwa/`, `home/`, `illustrations/`).
- `src/context/AuthContext.tsx` – auth + roles; falls back to a demo customer when Supabase is not configured.
- `src/context/AppContext.tsx` – app-wide state (offices, bookings, buddies, disputes), seeded from `src/lib/data.ts`.
- `src/lib/supabase.ts` – Supabase client; `isSupabaseConfigured()` is false with the mock URL/key, which puts the app in demo mode.
- `src/lib/i18n.ts` – translations for `en`, `kn` (Kannada), `hi`.
- `src/lib/capacitor.ts` – wrappers for native camera, GPS and push; check `isNativeApp()` before using native features.
- `src/middleware.ts` – passes public paths through and adds security headers.
- `supabase/` – SQL migrations (schema, `user_roles` + RLS), seed, cron jobs, and the `razorpay-webhook` Edge Function.
- `public/` – PWA files (`manifest.json`, `sw.js`, icons). Icons are generated by `scripts/generate-pwa-icons.mjs`.

## Auth and roles

Roles live in `public.user_roles` and are enforced server-side through RLS and security-definer functions (`get_user_role`, `get_admin_subrole`). Never trust a role sent by the client. Roles: `customer` (default on sign-up), `buddy` (must be approved before seeing jobs), and admin sub-roles `super_admin`, `ops`, `support`, `content`. Admins need TOTP MFA.

## Environment

Copy `.env.example` to `.env.local`. `NEXT_PUBLIC_DEMO_MODE=true` (or leaving the mock Supabase values) lets the whole app run without a backend. Never commit `.env` / `.env.local`.

## Android (Capacitor)

- `capacitor.config.ts` loads a **remote site** in the WebView so Supabase Auth, OAuth, API routes and Realtime work. `server.url` is `CAPACITOR_SERVER_URL`, else `NEXT_PUBLIC_APP_URL`, else `https://queuebuddy.vercel.app`. The Capacitor CLI does not read `.env` files, so set these in the shell. `webDir` is `public`, which holds only the PWA files. Set `CAPACITOR_LIVE=false` to drop the server URL.
- The URL is baked into `android/app/src/main/assets/capacitor.config.json` at sync time, so the app keeps whichever URL the last `cap sync` / `cap run` used.
  - Local testing: run `npm run dev`, then `npm run cap:run:local` (uses `http://10.0.2.2:3000`, the emulator's alias for the host's localhost).
  - Back to the live site: `npm run cap:run` (or `CAPACITOR_SERVER_URL=https://<your-site> npx cap run android`).
- Toolchain: **Java 21** (`export JAVA_HOME=$(/usr/libexec/java_home -v 21)`), Android Gradle Plugin and Gradle wrapper versions in `android/build.gradle` and `android/gradle/wrapper/gradle-wrapper.properties`, SDK levels in `android/variables.gradle`. Capacitor 8 needs compileSdk 36 and minSdk 24 or higher.
- Files marked "DO NOT EDIT" under `android/` (`capacitor.settings.gradle`, `app/capacitor.build.gradle`, `capacitor-cordova-android-plugins/`) are regenerated by `cap sync`; change `variables.gradle` or the top-level Gradle files instead.
- Push notifications only work when `android/app/google-services.json` exists.
- Emulators: for API 36+ images the emulator falls back to software GLES ("swangle"), which draws the WebView with duplicated/ghost cards. This is an emulator bug, not an app bug. Boot with `emulator -avd <name> -gpu host` (or set Graphics to Hardware in the AVD) before judging layout on an emulator.
- Keep `@capacitor/cli` on the same major version as `@capacitor/core` / `@capacitor/android`.
